PROJETO ORÇAMENTO DE ALUGUEL - IMOBILIÁRIA R.M

1. Abra o terminal nesta pasta.
2. Instale o Flask:
   pip install -r requirements.txt
3. Inicie o projeto:
   python app.py
4. Abra no navegador:
   http://127.0.0.1:5000

Depois de calcular um orçamento, clique em:
"Baixar CSV dos 12 meses".

Arquivos principais:
- app.py: rotas e integração com o navegador.
- imobiliaria.py: classes e regras de cálculo.
- templates/index.html: formulário e resultado.
