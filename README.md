# Orçamento de Aluguel

Projeto acadêmico desenvolvido em Python para gerar orçamentos mensais de aluguel para a imobiliária R.M.

## Objetivo

Automatizar o cálculo de orçamentos de locação de apartamentos, casas e estúdios, considerando valores básicos, adicionais, descontos e o valor do contrato imobiliário.

## Funcionalidades previstas

- Orçamento para apartamentos, casas e estúdios
- Cálculo de adicionais por quartos
- Inclusão de garagem ou vagas de estacionamento
- Desconto de 5% no aluguel de apartamentos para clientes sem crianças
- Inclusão do contrato imobiliário de R$ 2.000,00, parcelável em até 5 vezes
- Apresentação do valor mensal orçado
- Geração de arquivo CSV com as 12 parcelas do orçamento

## Tecnologias utilizadas

- Python
- Programação orientada a objetos
- CSV

## Como executar

1. Tenha o Python instalado no computador.
2. Baixe ou clone este repositório.
3. Abra a pasta do projeto no VS Code.
4. Execute o arquivo principal do projeto.

```bash
python main.py
```

> Caso o arquivo principal tenha outro nome, substitua `main.py` pelo nome correto.
